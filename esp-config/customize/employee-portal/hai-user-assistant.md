# HAi User Assistant

HAi User Assistant is an AI-powered self-service capability designed to help end users get the support and information they need more quickly. It provides a conversational way for users to ask questions, find answers, and receive guidance without needing to navigate complex systems or wait for direct analyst intervention.

![HAi User Assistant](/_books/esp-config/customize/employee-portal/images/hai-user-assistant.png)

## Before you begin

* **Join the Hornbill Early Access Program**: To access HAi User Assistant, you need to be part of the Hornbill Early Access Program. Please contact your Hornbill account manager for more information.
* **HAi User Assistant role**: A user must have the [HAi User Assistant](/esp-config/organizational-data/roles#hai-roles) role to access the assistant and its features.
* **Enable the HAi User Assistant**: The user assistant must be enabled in the [HAi configuration](/esp-config/integration/hornbill-ai#settings).

## Purpose

The purpose of HAi User Assistant is to improve the user support experience by:

* Providing fast access to helpful information.
* Reducing the effort required to log or manage support requests.
* Guiding users to the right service or support path.
* Improving self-service adoption.
* Reducing avoidable contact to the service desk.

HAi User Assistant acts as a digital support assistant, helping users resolve simple issues independently while ensuring more complex needs are directed appropriately.

## What HAi User Assistant can do

Depending on how it is configured and used, HAi User Assistant can help with tasks such as:

* Answering common support questions.
* Guiding users through support processes.
* Helping users find relevant knowledge and documentation.
* Assisting with raising requests or selecting the correct service.
* Collecting key information before a request is submitted.
* Providing updates or clarifying next steps in a support journey.

This creates a simpler and more accessible support experience for users.

## Benefits

Using HAi User Assistant can provide a number of benefits, including:

* Faster access to support and information.
* Improved user experience.
* Increased self-service success rates.
* Reduced demand on service desk teams for routine queries.
* Better quality information captured at the point of request.
* More consistent support journeys.

These benefits help both end users and support teams by improving efficiency and reducing friction.

## How it supports users

HAi User Assistant is designed to make support easier to access and simpler to use. Instead of relying only on forms, portals, or direct analyst contact, users can interact with a conversational assistant that helps them understand what they need to do next.

It supports users by:

* Simplifying access to support.
* Reducing uncertainty when raising requests.
* Helping locate the right information quickly.
* Making service interactions feel more natural and guided.

## Typical use cases

Examples of where HAi User Assistant may be useful include:

* Helping a user find an answer to a common issue.
* Guiding a user to the correct request type or service.
* Collecting information needed to log a support request.
* Directing a user to relevant knowledge before a ticket is raised.
* Assisting users with basic service-related questions.

## Summary

HAi User Assistant is an intelligent self-service tool that helps users get support more easily and efficiently. By offering conversational guidance, access to useful information, and support with request submission, it improves the user experience while helping organizations deliver more effective and scalable support.
