# Insights

Enable HAi Insights sidebar. Users that have the [HAi Insights role](https://docs.hornbill.com/esp-config/organizational-data/roles#hai-roles) will have access to HAi Insights from the right-hand side bar.  HAi Insights is context sensitive and provides relevant information based on the user's current activity.

* When viewing the request list, HAi Insights will analyze the requests in the request list to make recommendations about priorities and matching similar requests.
* When viewing a request, HAi Insights will analyze the request, providing summaries and possible next actions.
