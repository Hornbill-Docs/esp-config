# HAi User Assistant

The HAi User Assistant is a feature that allows users to interact with the HAi system through a conversational interface. It provides a way to ask questions and receive recommendations based on the data available in the system.

Before enabling this feature, review the User Assistant [Guardrails](https://docs.hornbill.com/esp-config/integration/hornbill-ai#guardrail-configuration) and [Customization](https://docs.hornbill.com/esp-config/integration/hornbill-ai#guardrail-configuration) options.
