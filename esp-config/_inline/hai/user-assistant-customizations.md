# User Assistant Customizations

Enable Customization options for the HAi Assistant.

## Tone of Voice

The tone of voice for the HAi Assistant can be customized to match the desired communication style. This includes options for formality, helpfulness, and overall demeanor.

## Instructions

The instructions for the HAi Assistant can be customized to provide specific guidance on how to interact with the system. This includes options for response format, handling of sensitive information, and general interaction protocols.
