# User Assistant Guardrails

Select the toggle located in this title bar to enable the **User Assistant Guardrails**. Once enabled, you can provide input rules to set boundaries for the **HAi User Assistant**. For example, you can restrict access to sensitive data or limit the types of actions the assistant can perform.
