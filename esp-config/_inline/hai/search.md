# HAi Search

Enable AI Search for HAi and the HAi Assistants.

When this is enabled, the HAi Search Indexes will start to build. This can take up to 72 hours to complete, depending on the amount of data in your environment. The HAi Search Indexes section will be displayed along with the status of each index. Once the indexes are built, the status will show as **Available**.

If you are no longer using any of the HAi tools, you can disable the HAi Search feature. This will remove the HAi Search Indexes. Turning this back on will require the indexes to be rebuilt.
